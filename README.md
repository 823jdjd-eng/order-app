# 雨石屋智能点餐系统

一个基于 Flask 构建的移动端点餐网站，包含顾客点餐端、商家后台、订单同步、余额支付、优惠券、积分签到、幸运转盘、顾客消息、投诉反馈和 AI 智能点餐助手等功能。

项目面向小餐馆、校园档口、社区餐饮店等轻量餐饮场景，目标是用一个普通手机浏览器就能完成点餐、接单、沟通和运营管理。

## 项目亮点

- 移动端优先设计，适合手机扫码点餐和浏览器访问
- 顾客端支持注册登录、菜品浏览、分类筛选、搜索、购物车和订单确认
- 菜品支持配菜选择，不同配菜会自动计入订单价格
- 商家后台可以实时查看订单、修改状态、管理用户和处理顾客消息
- 支持余额支付，余额不足时禁止提交订单
- 支持商家给指定用户充值，也支持负数扣款
- 支持优惠券系统，包括未使用、已使用、删除、指定菜品券、五折券和无门槛券
- 支持积分签到，积分可兑换优惠券
- 支持幸运转盘，消耗余额后按概率发放余额、优惠券、免费餐券或空奖
- 支持顾客和商家双向聊天，商家可在后台回复
- 支持投诉反馈，商家可在后台处理
- 预留 AI 智能体能力，可接入大模型 API 做智能推荐点餐

## 功能模块

### 顾客点餐端

顾客可以在首页浏览店铺信息、进入点餐页面、查看菜品详情、选择配菜、加入购物车并完成余额支付。下单时可以填写手机号、预计取餐时间和备注，方便商家制作和联系。

### 商家后台

商家后台用于处理真实经营流程。商家可以查看订单列表、修改订单状态、查看用户列表、删除用户、给用户充值、处理提现记录、回复顾客消息和处理投诉。

### AI 智能体

系统预留 AI 点餐助手区域，可接入智谱等大模型 API。后续可根据人数、预算、口味、忌口和当前菜单自动推荐菜品，并支持一键加入购物车。

### 余额与优惠券

用户可以查看余额、提交提现申请、查看充值提示。商家可以在后台为用户充值或扣减余额。优惠券支持按订单、指定菜品、任意菜品折扣等方式使用，已使用优惠券会自动作废。

### 幸运转盘

用户可使用余额参与幸运转盘。转盘奖品包括 20 元无门槛券、100 元余额、指定菜品免费券、任意菜品五折券、可乐兑换券和空奖。中奖后奖品会自动进入余额或优惠券。

## 项目定位

雨石屋智能点餐系统是一个面向真实餐饮场景的轻量化 Web 点餐应用。它不是单纯的页面展示，而是包含顾客下单、商家处理、余额支付、优惠券营销、消息沟通和 AI 推荐能力的完整业务闭环。

后续计划继续扩展微信支付、库存管理、销售统计、菜品上下架、多店铺管理、自动客服、AI 图片识别点餐和商家运营报表等功能。
